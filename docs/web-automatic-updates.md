# Автоматическое обновление веб-версии

Каждый выпуск содержит метку ersi-release в index.html, release.json и отдельный main.<commit>.dart.js. Скрипты установки и проверки обновлений также получают версию в URL. Оба пути публикации (publish-web-only и полный deploy) используют общий stamp_web_frontend.py, публикуют ресурсы раньше index.html и release.json последним. Старые versioned bundles сохраняются для уже открытых клиентов.

auto-update.js проверяет release.json без HTTP-кэша раз в 30 секунд, при возврате во вкладку/PWA, восстановлении сети и pageshow. Изменение передаётся другим вкладкам через BroadcastChannel, без пользовательских данных. Перед переходом скрипт сверяет версию с отдельно полученным index.html; незавершённая публикация не вызывает перезагрузку.

Свободная видимая страница обновляется сама после трёх секунд без взаимодействия. Перед обновлением не очищаются localStorage, авторизация и черновики. Заполнение инспекции, проверка качества, окна камеры/пароля/счёта и ввод данных блокируют автоматический переход. Появляется уведомление на русском/казахском. При успешной отправке/сохранении инспекции и выходе защита снимается. Уход с незавершённой инспекции в главное меню не считается сохранением. Принудительное обновление по кнопке требует подтверждения при наличии несохранённой работы.

Одна автоматическая попытка на версию в пределах вкладки предотвращает циклическое обновление. Отсутствие сети или неверный JSON не ломают рабочую страницу. Worker не хранит приложение/API в CacheStorage: навигация идёт с no-store, код и ресурсы приложения revalidate с no-cache. API и скачиваемые документы не кэшируются этим механизмом. Старый Flutter-кэш удаляется без удаления собственных/чужих worker-регистраций.

У старой страницы, открытой до внедрения этой функции, нет нового JS-проверяющего. Она получит его при следующем обычном открытии или обновлении страницы; вручную очищать кэш не требуется. После этого будущие выпуски определяются автоматически. Фоновые вкладки проверяются сразу при возвращении, поскольку браузер может приостанавливать их таймеры.
