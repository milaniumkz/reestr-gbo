# Вход по паролю

SMS-вход отключён. В приложении и админке используется номер телефона и пароль; для ИО и установщиков также указывается БИН организации.

При обновлении миграция `20261019110000_password_authentication` устанавливает всем существующим пользователям временный пароль `123456` и завершает старые сессии. Новые пользователи получают такой же временный пароль по умолчанию базы данных. Добавление существующего пользователя в другую организацию не сбрасывает его личный пароль.

Первый вход выдаёт только подтверждение смены пароля на 10 минут. Рабочая сессия создаётся после установки личного пароля минимум из 8 символов (максимум 72 байта UTF-8) и повторного ввода. Подтверждение одноразовое; оно не даёт доступа к рабочему API. Пароли хранятся только как bcrypt-хэши. После пяти неверных попыток вход ограничивается на 15 минут.

Старые APK с SMS-входом требуют обновления. Анонимная проверка свидетельств остаётся доступна.
