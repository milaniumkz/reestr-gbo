# Видеоинструкции

Обновление 27.10.2026: https://89-207-255-42.sslip.io/guides/index.html?v=language9

Пять самостоятельных инструкций: наблюдатель, инспектор, контроль качества, руководитель инспекционного органа и контрольный орган. Каждая начинается одинаковым разбором главного экрана, правовой информации, русского и казахского языков, трёх категорий участников. Завершение объясняет возможности проверки сведений для безопасности дорожного движения.

Для каждой роли опубликованы горизонтальная версия 1920×1080 с пояснениями и телефонная 1080×2260 с интерфейсом на весь экран. Использованы оригинальный логотип приложения и вымышленные учебные записи. Озвучка на русском языке, голос Svetlana, темп +14%. В речи используются полные названия органов, «казахский язык» и «государственный номер».

Инструкция инспектора показывает вход, начало новой инспекции, владельца, автомобиль, обязательные сведения о баллоне, отметку двух баллонов и второй номер. Для каждого баллона отдельно объяснены бирка, рабочая запись и отчёт. Финальный документ загружает отдел качества; руководитель утверждает и отправляет запись в реестр.

Стрелки синхронизированы с фактическими временами слов озвучки. Общие первые три главы совпадают между ролями в обоих форматах. Формат файлов: MP4, H.264/AAC, faststart; отдельные русские SRT сохранены рядом.

Публикация: workflow `publish-guides.yml` делает резервную копию, обновляет только статические инструкции и сравнивает скачанные файлы с исходниками. `web/guides/SHA256SUMS` содержит контрольные суммы. При обновлении проверяются кодеки, размеры, длительности, ссылки страниц, декодирование файлов и воспроизведение всех десяти видео в Chromium.

Обновление 28.10.2026: перед данными баллона добавлен отдельный фрагмент выбора тороидальной или цилиндрической формы с показом обеих кнопок и синхронной озвучкой. Во всех пяти инструкциях обновлён главный экран: уведомление о независимом частном сервисе показано внутри окна закона, на главном экране его нет.

Обновление 29.10.2026: общий фрагмент о языках перезаписан с заданным владельцем произношением «каза́хский язык», «каза́хского языка» (ударение на втором «а»). Ударение передаётся непосредственно в текст синтеза и входит в ключ аудиокэша; старый фрагмент без этого указания не используется. Во всех десяти версиях сохранены голос, темп, длительность и синхронизация стрелок.

Редакция language9 (29.10.2026): инструкция выбора языка перезаписана целиком. Формулировка: «Чтобы выбрать каза́хский язык, нажмите правую кнопку». Форма «казахского» в актуальном общем фрагменте больше не используется. Новая озвучка и соответствующие субтитры, времена стрелок обновлены во всех десяти версиях.
