# Публичная оферта ЕРСИ ГБО

Первое опубликованное издание: `offer-ru-v1`, дата редакции 24.10.2026. Исходник предоставлен владельцем в DOCX. Удалены пустое приложение 3 (бланк рекламного заказа) и незаполненные строки подписи. Ссылки на удалённый бланк заменены отдельным согласованным заказом. Заполненные приложения 1 и 2, цена 50 тенге в приложении 2 и реквизиты сохранены.

По прямому указанию владельца акцепт оформляется нажатием «Войти», без галочек. Изменены пункты 2.1–2.3 и связанные условия доступа: первоначальный аванс не нужен для принятия оферты. Платные условия разделов 4–5 применимы только после отдельного подключения и принятия тарифа; публикация не включает автоматические платежи и списания. Выставление счета на добровольный аванс не меняет баланс. Принятие оферты не подменяет отдельные согласия субъектов персональных данных (п. 8.2).

Публичные адреса:
- `/offer.html` — актуальная страница;
- `/legal/offer-ru-v1.html` и `/legal/offer-ru-v1.docx` — постоянные файлы редакции;
- `/legal/offer-ru-v1.json` — версия, SHA-256 канонического содержимого и скачиваемого DOCX;
- `/tariffs.html` — отдельно опубликованное заполненное приложение 2 с явным предупреждением, что платные операции не подключены;
- `/api/v1/legal/public/offer` — метаданные редакции.

Перед кнопкой входа размещены уведомление и ссылка. Новый веб-клиент/код приложения передаёт `offerVersion`; админка делает то же. При успешном входе сервер сохраняет `auth.offer_accepted` в существующий `AuditLog`: пользователь, организация (если идентифицирована при входе), версия, источник `login_button`, время БД и IP. При первом обязательном изменении пароля версия передаётся в подписанном ограниченном доказательстве, запись создаётся только после завершения смены пароля. Неверный пароль, просмотр страницы, продление сессии и старый клиент без уведомления не записываются как принятие. Существующим сеансам не приписывается задним числом согласие.

Опубликованные файлы редакции не перезаписывать. При последующих изменениях выпускается новая версия с новым идентификатором и сохранением прежних файлов. Не считать запись о нажатии доказательством прочтения текста или безусловным доказательством полномочий представителя: порядок полномочий регулируют пункты 2.4–2.5.

Проверка: `python3 scripts/check_public_offer.py`, тесты аутентификации, `flutter analyze`, `flutter test`, сборка админки. Проверка документа включена в CI и workflow развёртывания. Веб-версия выкладывается отдельно; установленный APK получает уведомление о принятии только после обновления клиентского кода.
