# Проверка выпуска технической панели

Проверки выполнялись на локальной PostgreSQL 16, отдельной БД reestr_test и искусственных пользователях. Рабочие ИО, документы и пароли в тестах не использовались.

- Backend: 185 тестов, 25 наборов; отдельные проверки городов обоих участников, неизвестных и недостоверных координат, переименований, улиц, неоднозначных владельцев; RFC TOTP, повтор кода, AES-GCM, права и очистка журналов.
- HTTP: 47 проверок с настоящей PostgreSQL: предварительный MFA-сеанс не читает данные; все разделы отвечают; support получает 403 на персональные/инфраструктурные разделы; CSRF; одноразовое восстановление при двух одновременных запросах; повтор ошибки открывает расследование; триггер запрещает изменение/удаление события; hold; карантин блокирует выдачу файла.
- Браузер Chromium: вход, 11 разделов с настоящими ответами API, география обоих участников; светлая/тёмная темы; desktop 1440, tablet 820, mobile 390; проверка отсутствия горизонтального переполнения страницы и JavaScript/HTTP500 ошибок.
- Next: production build технической панели и обычной админки.
- Архивирование: проверена запись зашифрованного архива перед удалением истёкшего события; действующий hold сохранил вторую запись в БД.
- Резервирование: pg_dump → отдельная БД pg_restore --exit-on-error; проверены технические аккаунты, события и инспекции. Два искусственных файла также прошли tar-восстановление с совпадением SHA-256. Это синтетические тесты, не подтверждение всех production-копий.
- Скриншоты в screenshots/: только синтетические данные, с явной отметкой тестовой среды. Пароли и MFA-ключи не фотографировались.

## Вход только по паролю — 19.10.2026

По прямому запросу владельца обязательный MFA удалён из входа и повторного подтверждения. В техническую панель допускается только `owner`; остальные технические аккаунты отключены и запрещены серверной проверкой. Создание новых технических аккаунтов запрещено. Пароли не менялись, старые технические сеансы отозваны. Пользователей приложения и сотрудников ИО это не затрагивает.

Проверены 185 unit-тестов, 39 HTTP-проверок и браузерный вход без поля кода, включая подтверждение операций одним паролем. Тест с ранее настроенным MFA также проходит без кода; другой активный технический аккаунт с правильным паролем получает отказ. Скриншот: screenshots/login-password-only.png.
