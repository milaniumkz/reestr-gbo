# Номера свидетельств внутри инспекционного органа

Номер уникален только внутри ИО. Например, ИО A и ИО B могут независимо создать свидетельство «3»; повторить «3» внутри одного ИО нельзя. Проверки создания, исправления, выдачи и XLSX-импорта используют ИО. База обеспечивает уникальность `(organizationId, certificateNumber)` для инспекций и `(organizationId, number)` для свидетельств; составной внешний ключ не позволяет привязать свидетельство к инспекции другого ИО.

Читаемый номер не является глобальным идентификатором. Карточки, изменение статуса, PDF, история проверок и новые QR используют ID свидетельства. Для старых интеграций `/certificates/:number` допускает `organizationId` в query; без него неоднозначный номер отклоняется. Точный старый QR проверяется по сохранённому payload. PDF хранятся под ID, а исходные XLSX — под хешем файла, поэтому документы с одинаковыми номерами не перезаписывают друг друга.

Миграция сохраняет номера, идентификаторы и QR существующих свидетельств. Принадлежность свидетельства и связанных импортов определяется по его инспекции. Проверено на отдельной PostgreSQL: одинаковый «3» в разных ИО проходит, повтор в одном ИО и связь с чужой инспекцией отклоняются, исходные данные сохраняются.
