# Установка веб-версии

Manifest содержит постоянный id/scope/start_url, display standalone и реальные иконки приложения. На первом входе после готовности Flutter появляется окно с логотипом. Chrome/Edge при наличии beforeinstallprompt предлагают установку по нажатию пользователя. Автоматически открывать системное окно без жеста браузер не разрешает. На Safari/iPhone отображается инструкция «Поделиться → На экран Домой»; неподдерживающие native prompt браузеры получают инструкцию через меню.

Отказ скрывает приглашение на сутки. Открыть его повторно можно из профиля. Установленный режим и событие appinstalled скрывают приглашение; полученный впоследствии beforeinstallprompt снимает сохранённую отметку об установке. RU/KK выбирается по настройке приложения. Это установка веб-приложения, а не загрузка APK.

Старый Flutter service worker удаляется отдельно; новый ersi-pwa-sw.js и чужие worker-регистрации не удаляются. Новый worker не хранит Flutter-код, API или персональные данные в кэше. При отсутствии сети навигация показывает понятную ошибку. Установка не отменяет разрешения камеры/GPS: они по-прежнему выдаются пользователем в браузере.

На стартовом экране и в маленьком значке используется assets/branding/ersi-gbo.png, точная копия официальной web/icons/Icon-512.png, вместо рисунка из стандартных иконок.

Для изменений только фронтенда workflow publish-web-only.yml собирает/проверяет Flutter web, сохраняет резервную копию данных и снимок текущего фронтенда, публикует файлы с index.html последним, сохраняет старые версионные bundles для открытых клиентов и проверяет неизменность APK. Backend/админка/БД не переустанавливаются и не перезапускаются. frontend-commit.txt фиксирует отдельную версию фронтенда. Следующий полный deploy использует те же исходники web.
