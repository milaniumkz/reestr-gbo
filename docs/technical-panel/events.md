# Каталог событий

| Группа | Уже есть в AuditLog | Дополнения |
|---|---|---|
| Вход | auth.login, auth.password_failed, auth.refresh, auth.logout, auth.password_changed | Окончательные отказы 401/403, rate-limit, технический вход/выход/MFA, выдача/использование одноразового восстановления |
| Доступ | user.role.add/remove, user.block/unblock, organization.member.add/remove | Технические роли, отзыв сеансов, безопасная разница ролей и флагов, причина и срок ограничений |
| Реестр | vehicle.upsert, inspection.create/data.update/status.update/delete, certificate.status.update, import_xlsx | Корреляция с HTTP-запросом, ошибки/отказы, безопасная разница разрешённых полей |
| Качество | claim/release/quality.data.update, подтверждения статуса | Исполнитель, результат, номер обращения |
| Файлы | inspection.photo.upload; метаданные StorageObject | Результат проверки, карантин/ручная проверка, хеши повторов, авторизованный просмотр оригинала, отказ/ошибка чтения |
| Документы | Изменения/импорт свидетельств | Запрос/выдача PDF и экспорта; физическая печать не подтверждается |
| Уведомления | notification.create/read/delete | Группировка тревог, получение/приглушение/взятие в работу; внешний канал «Не подключено» |
| Обслуживание | Скрипты/Actions | Сбор метрик, сведения копий/выпусков, безопасная повторная проверка, попытки опасных операций и отказы |

Новая запись: UUID, серверное время, источник (сервер/клиент/технический сотрудник), действие, категория, результат, объект без содержимого, requestId, actorId/роль/сеанс, версия и доступные технические признаки. IP и устройство — отдельные защищённые поля, не включаются в обычный экспорт.

Разрешённые изменения: статус, роль, isBlocked, признак активности, тип, назначение проверяющего и технические настройки. ФИО, ИИН/БИН, VIN, номера документов, телефоны, адреса, пароли, токены, cookies и содержимое файлов не копируются в разницу. Свободные причины/комментарии очищаются и ограничиваются по длине.

## Не является доказательством

Клиентский клик, приблизительная IP-география, необычная фотография, совпадение хеша, запрос печати, постановка уведомления в очередь. Значения имеют отдельные подписи и не превращаются в обвинение или факт доставки/печати.
