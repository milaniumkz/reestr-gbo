# Фактическое место инспекции

Адрес инспекции определяется сервером по GPS устройства, полученному при создании инспекции. Адреса организации, владельца и переданная клиентом строка адреса для этого не используются. Если обратное геокодирование недоступно, создание останавливается до успешного повторного определения адреса. Без корректной пары координат сервер также отклоняет создание.

Приложение запрашивает текущее местоположение. При отказе, отключённой геолокации или ошибке отправка останавливается с уведомлением: включить геолокацию, проверить разрешение приложению/сайту, выключить и снова включить геолокацию и повторить отправку. Подстановка координат офиса или координат предыдущей инспекции удалена. Старые версии приложения следует обновить: сервер не может отличить подставленные старым клиентом координаты от его настоящего GPS.

В аудит создания записываются координаты, адрес и источник адреса. Исторические записи автоматически массово не меняются. Для подтверждённого случая №10425 предусмотрено точечное исправление адреса по уже сохранённому GPS: workflow repair-inspection-address.yml. Требуются номер и SHA-256 текущего адреса; конкурентное изменение отменяет операцию. Координаты не меняются, старый и новый адрес сохраняются в аудите. Если геокодер не отвечает, исправление не выполняется.


## Обязательное определение адреса

Новая инспекция не создаётся, а существующая не отправляется дальше по проверке без адреса. GPS-строка не считается адресом. На шаге владельца и перед сохранением приложение проверяет адрес через сервер и показывает результат. Если адрес не получен, диалог блокирует продолжение и предлагает «Попробовать снова определить адрес»; отмена оставляет пользователя на текущем шаге. Для исправления существующей инспекции используется её сохранённый GPS, а не местоположение сотрудника контроля качества.

Геокодеры используют HTTPS по IPv4: на production IPv4 Nominatim отвечает, а IPv6-маршрут недоступен. При сбое основного сервиса используется Photon. Принимается только ближайший результат в пределах 100 метров с населённым пунктом и улицей; номер дома выводится, если он есть в картографических данных. Далёкий объект или один лишь город не подставляются вместо адреса. Успешные результаты кратковременно кешируются, одинаковые параллельные запросы объединяются, неуспешные результаты можно сразу повторить. Исторические исправления выполняются по исходному GPS с проверкой конкурентных изменений и аудитом.
