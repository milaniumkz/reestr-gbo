# Русская озвучка видеопроверки

Встроенные WAV-файлы произносятся женским голосом Piper `ru_RU-irina-medium` с коэффициентом длительности 0.78 вместо прежнего 1.05; темп рассчитан на обычную разговорную речь. Модель работает только при подготовке аудиофайлов. В приложение и серверный видеомодуль она не включается; внешних TTS-запросов при проверке нет.

Источник: https://huggingface.co/rhasspy/piper-voices/tree/e7229f7d33a10e145e109b886d661984201ac3c4/ru/ru_RU/irina/medium. Репозиторий указывает MIT; исходная карточка голоса описывает датасет RHVoice без отдельного обозначения лицензии датасета. Атрибуция: Piper/rhasspy, RHVoice, голос Irina.

Подготовка: `pip install piper-tts==1.4.1`, затем `python scripts/generate_identity_voice.py --model-dir /tmp/intercity-voice-model`. Загрузка закреплена версией репозитория и SHA256 модели и конфигурации. Сведения о фразах, длительности и хешах готовых файлов находятся в `identity-voice.json`.

Команда «Смотрите прямо» длится менее 1.8 секунды, подготовка к записи — менее 2.9 секунды, команда действия — менее 3 секунд. Эти ограничения сохраняют паузу на реакцию в серверном задании. Лишняя тишина по краям обрезана с небольшими полями, громкость выровнена с запасом до ограничения сигнала. Паузы между действиями остаются в управлении видеопроверки. WAV: mono, PCM16, 22050 Hz.
