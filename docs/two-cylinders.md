# Два баллона в одной системе ГБО

Флажок «Используются два баллона» добавляет отдельные поля второго баллона:
тип (тороидальный/цилиндрический), номер, производитель, объем, полная дата выпуска.
Эти пять значений обязательны и не подставляются из первого баллона. Тип газа,
редуктор и ЭБУ вводятся один раз в общем блоке ГБО. Дата инспекции общая; сроки
освидетельствования рассчитываются по общему типу газа (СНГ — 2 года, КПГ — 3).

Для каждого баллона отдельно нужны фото бирки, рабочая запись с подписями,
отчёт инспекции с подписью/печатью и файл свидетельства. Первые три документа
предоставляет инспектор; два файла свидетельств загружает контроль качества.
Инспекция, её номер, согласование руководителя и запись в реестре остаются одними.
Без обоих файлов свидетельств и подтверждения качества передача руководителю
блокируется сервером и интерфейсом. При возвращении на исправление отметки
загрузки свидетельств сбрасываются; смена номера второго баллона исключает
документы прежнего баллона из действующего комплекта.

Миграция добавляет nullable-поля в Inspection для второго баллона, отдельную отметку
загрузки второго свидетельства и GasCylinder.shape для типа первого баллона.
Старым записям не приписываются неизвестные характеристики. Старые записи доступны
для просмотра; при редактировании новой формой требуется заполнить второй блок.
Старые клиенты без второго блока не могут создавать новые двухбаллонные инспекции:
сервер предлагает обновить приложение или использовать веб-версию.

Данные второго баллона возвращаются в карточках инспекции/свидетельства, реестре,
обычной админке и PDF. Наблюдатель может открыть оба свидетельства и техпаспорт;
рабочие записи и отчеты не становятся доступны наблюдателю. Удаление флажка
очищает второй блок и исключает его документы, не затрагивая первый баллон и
общие данные ГБО. Исходные файлы сохраняются в техническом журнале.

Проверки: полный backend/Flutter набор; сборка админки; обязательность независимых
полей; переключение одного/двух баллонов; разные объемы/типы/даты; отсутствие
второго типа газа/ЭБУ/редуктора; восстановление JSON; цепочка инспектор → два
свидетельства качества → руководитель; устаревшие документы при смене баллона;
формирование PDF с двумя наборами полей и одним набором данных ГБО.
